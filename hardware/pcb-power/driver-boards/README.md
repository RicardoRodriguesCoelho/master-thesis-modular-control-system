# Gate Driver Boards

This folder contains the **isolated gate driver boards** developed for the power electronics stage.

Two driver implementations are provided due to component availability constraints during the project.

## Available Driver Boards

- `adum3223/` – Driver board based on the ADuM3223 isolator
- `adum4135/` – Driver board based on the ADuM4135 isolator

Both versions provide equivalent functionality and interface with the same power main board.

## Design Considerations

The alternative driver implementations ensured project continuity when specific components became unavailable, without impacting system functionality or performance.
